# rules.example.md

空白模板。把你的账号立场、文风标准与格式要求写进这里；`rules/rules.md` 是插件侧规则解析器的唯一记忆来源。

## 建议分区

| 分区 | 写什么 | 机器可执行形式 |
|---|---|---|
| 立场 | 哪些 framing 不写、哪些边界不越 | 关键词/短语黑名单 |
| 文风 | 破折号上限、加粗数量上限、禁用过渡词、绝对词软化表 | 计数规则 + 正则 |
| 查重 | 时间窗口、相似度算法、类别标签 | 参数 |
| 系列衔接 | 允许与禁止的篇间指代词 | 词表 |
| 信源 | 是否必须有信源栏、未核实段落如何标注 | 结构检查 |
| 排版 | 内联字体、块背景、图片内嵌方式、封面比例 | 结构检查 |

## 两条实测经验

1. **规则要能执行，不要写成口号**。「少用 AI 味」机器查不了，「破折号 ≤3 处 / 加粗 ≤8 处 / 禁用词表」才查得了。
2. **形式检查全绿不等于可发布**。立意、读者兴趣、数字与实物是否对得上，机器查不了。规则之外留一道人工门禁，别把 0 违规当放行。
